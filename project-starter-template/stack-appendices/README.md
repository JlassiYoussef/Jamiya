# Stack Appendices

The root template is stack-agnostic. Pick the appendix that matches your team's
stack, follow it, then **delete this `stack-appendices/` folder** so your repo
stays clean.

- [node.md](node.md) — JavaScript / TypeScript web apps (React, Next, Node, etc.)
- [python.md](python.md) — Python backends, data, and ML
- [other.md](other.md) — Mobile (Flutter/iOS/Android), Java/Kotlin, and anything else

Each appendix tells you: what to add to `.gitignore`, how to set up formatting/
linting, how to add a test command, and how to make CI run it.
